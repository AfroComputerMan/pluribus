Create `src/lib/providers/codex-provider.ts` implementing the AgentProvider interface. Use the existing `codex-adapter.ts` as reference for the Tauri invoke/listen pattern and event mapping, but write the implementation fresh conforming to the new interface.

**Provider factory:** `createCodexProvider(): AgentProvider`

**Properties:**
- `id: "codex"`
- `displayName: "Codex"`
- `capabilities: { supportsResume: false, supportsApproval: true, supportsSubAgents: false, supportsMcp: false, supportsEffort: true }`
- `supportedModels`: Import from `CODEX_MODELS` in models.ts, map to IDs

**run(ctx: RunContext) implementation:**
- Call `invoke<string>("codex_start_thread", { model: ctx.model, reasoningEffort: ctx.effort })` to start a Codex thread
- Set up `listen<AgentEvent>("agent:event", handler)` filtered by the returned codexThreadId
- Convert AgentEvent payloads to ChatModelRunResult yields:
  - `agent_message` events -> text content parts
  - `file_change`, `command_execution` events -> tool call content parts (follow existing codex-adapter mapping for toolCallId, toolName, args)
  - `reasoning` events -> metadata/thinking parts if applicable
- Handle the approval flow: when Codex requests tool approval, integrate with `useCodexApprovalStore` (keep existing store, it already works)
- On completion event: yield final result, clean up listener
- On error: throw, clean up listener
- Handle ctx.abortSignal: when aborted, call `invoke("codex_interrupt_turn", { threadId: codexThreadId })` and clean up
- Fire ctx.onDevEvent for each agent event

**interrupt(threadId) implementation:**
- Call `invoke("codex_interrupt_turn", { threadId })`

**PID retrieval for process manager:**
- Export a helper `getCodexPid(): Promise<number | null>` that calls `invoke<number | null>("codex_get_pid")`
- The process manager (or orchestrated adapter) will call this after starting a Codex thread to register the PID

Note: Codex config isolation (PROV-07) is handled via the Codex app-server API's thread-scoped config -- no additional work needed per the research.
